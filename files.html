Вимоги до 3D-моделі

Мінімальна товщина стінки Від 1.0 мм для FDM-друку, від 0.5 мм для SLA-смоли.
Водонепроникна сітка (Watertight mesh) Модель не повинна мати отворів у поверхні. Перевірте у Meshmixer або Netfabb.
Одиниці вимірювання — міліметри Якщо модель у дюймах або сантиметрах — обов'язково вкажіть це у повідомленні.
Кількість трикутників (STL) Оптимально 100к–2М полігонів. Надто висока деталізація уповільнює обробку.

Як правильно надіслати файли

  1. Стисніть файли у ZIP-архів без паролю
  2. Надішліть на email@techplast.ua або в Telegram @tech_plast
  3. Вкажіть: кількість виробів, бажаний матеріал, колір та термін
  4. Для файлів понад 25 МБ використовуйте Google Drive або WeTransfer
Файл у Telegram — зручно для файлів до 50 МБ. Для більших — надсилайте посилання на хмарне сховище.

Часті питання

Який формат краще — STL чи STEP?

Для механічних деталей — STEP (точніша геометрія). Для декору та фігурок — STL або OBJ.

Чи можна надіслати фото деталі замість файлу?

Так, виконаємо реверс-інжиніринг. Результат залежить від якості фото та складності деталі.

Чи потрібно вказувати орієнтацію при друку?

Якщо є критичні вимоги — вкажіть у повідомленні. Інакше технолог обере оптимальну орієнтацію самостійно.

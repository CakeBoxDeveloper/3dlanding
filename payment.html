Оплата

Способи оплати

Зручні варіанти оплати для фізичних осіб та підприємств. Безготівковий розрахунок, картка, LiqPay та Monobank.

Для фізичних осіб

Банківська картка (Visa / Mastercard) Онлайн-оплата через захищену платіжну форму.
LiqPay Зручна оплата через застосунок Приватбанку.
Monobank Переказ на картку або через QR-код.
Накладений платіж Нової Пошти Оплата при отриманні — для замовлень до 5 000 грн.

Для юридичних осіб та ФОП

Безготівковий розрахунок Виставляємо рахунок-фактуру з ПДВ або без. Акт виконаних робіт в електронному та паперовому вигляді.
Оплата за договором Для регулярних замовників та підприємств — індивідуальні умови.
Тендерні закупівлі Працюємо з ProZorro та державними підприємствами.
Для безготівкового розрахунку — надайте реквізити компанії при оформленні замовлення.
